23CSE498 — Project Phase 2

Cross-Domain Weighted Graph Matching Using an Enhanced GNCCP Optimization Framework

We match subgraphs of a specified size across two weighted graphs by combining a Frank-Wolfe-optimized GNCCP relaxation for topological correspondence with a Kabsch-based 3D verification stage. A single pipeline is validated across three unrelated domains — temporal social networks, Drosophila brain connectomes, and molecular crystal structures — without changing the underlying matching algorithm.

Problem statement

Given two labeled weighted graphs G and H of size M and N, and an integer L ≤ M ≤ N, Weighted Common Subgraph (WCS) matching seeks the partial permutation matrix that identifies the L most structurally and semantically similar vertices between the two graphs. The problem is NP-hard in general, and existing two-step schemes (match everything, then rank) are not consistent with the joint optimum.

This project targets an approximate solver that (a) scales to graphs with thousands of nodes, (b) generalizes across domains with heterogeneous edge semantics, and (c) optionally incorporates 3D spatial coordinates when available, without requiring a domain-specific redesign of the core algorithm.
