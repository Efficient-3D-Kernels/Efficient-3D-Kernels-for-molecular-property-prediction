2 · Cost matrix C — how different does every atom pair look?

One row per query atom, one column per candidate atom. Each cell is a dissimilarity score, not a match/no-match flag — this is the matrix that is not 0/1. It's built from three things: element mismatch (0 if same element, otherwise a flat penalty of w_elem = 3.0 — chemistry is never allowed to cross), plus a small penalty for having a different number of bonds, plus a small penalty if the neighboring atoms' elements don't match either. Darker teal = looks similar; red = looks very different. The 0/1 decision happens later, in Step 3.

0 (identical)

3 · GNCCP optimization — from a fuzzy guess to a hard match

GNCCP starts by assuming every candidate atom is equally plausible for every query atom (left matrix — every cell holds the same tiny fraction). It then homotopes a parameter ζ from +1 to −1 (Frank-Wolfe + Hungarian solving the inner step each time), gradually sharpening that fuzzy guess. By the end, exactly one 1 per row survives (right matrix) — a real one-to-one assignment. This is the matrix that is 0/1, and only this one.

5 · 3D verification — does it actually overlay in space?

A 2D/topology match doesn't guarantee the atoms sit in the right place in 3D. We take the matched atoms, find the best-fit rotation (Kabsch, Theorem 4), and measure how far apart they still are afterward (RMSD, in Ångströms). Under 2.0 Å is the field-standard "real match" cutoff; above it, it's flagged a 3D decoy — same chemistry, wrong shape. The bond/angle/torsion check is a second, independent opinion using local geometry rather than the whole-motif overlay.
